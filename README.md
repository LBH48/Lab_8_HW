# Домашнее задание к работе 8

## Условие задачи

Вычислить для заданного натурального `n` и действительного `x` с использованием цикла `for` значение:
sin(x) + sin²(x) + ... + sinⁿ(x)

## 1. Алгоритм и блок-схема

**Алгоритм решения:**
1. НАЧАЛО
2. Ввести натуральное число n и действительное число x.
3. Инициализировать переменную sum значением 0.0.
4. Вычислить начальное значение степени stepen = sin(x) и сохранить s = sin(x).
5. Запустить цикл for для i от 1 до n.
6. Внутри цикла: прибавить stepen к sum, затем умножить stepen на s.
7. Вывести полученное значение sum.
8. КОНЕЦ

**Блок-схема:**
flowchart TD
    Start([Начало])
    Input[/Ввод n, x/]
    Init1["sum = 0.0"]
    Init2["stepen = sin(x)"]
    Init3["s = sin(x)"]
    Init4["i = 1"]
    Cond{"i <= n"}
    Body1["sum = sum + stepen"]
    Body2["stepen = stepen * s"]
    Body3["i = i + 1"]
    Output[/Вывод sum/]
    End([Конец])

    Start --> Input
    Input --> Init1
    Init1 --> Init2
    Init2 --> Init3
    Init3 --> Init4
    Init4 --> Cond
    Cond -- Да --> Body1
    Body1 --> Body2
    Body2 --> Body3
    Body3 --> Cond
    Cond -- Нет --> Output
    Output --> End

## 2. Реализация программы
